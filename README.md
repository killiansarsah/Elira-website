# Elira Website

Modern, responsive website for Elira built with React, TypeScript, Tailwind CSS, and Vite.

## 🚀 Features

- **Modern Hero & Interactive Canvas**: Dynamic gradients and animated typography.
- **Glassmorphic UI**: Translucent glass panels, smooth blur effects, and responsive navigation.
- **Interactive Product Showcase**: Interactive tabs and feature breakdowns.
- **Partner Showcase & Marquee**: High-performance ticker for brands and clients.
- **Smart SaaS Integration & CTA**: Clean, conversion-focused sections.
- **Full Responsiveness**: Optimized for mobile, tablet, and desktop screens with dark-mode styling.

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Bundler & Tooling**: [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)

## 📦 Getting Started

### Prerequisites

- Node.js (v18+ recommended)
- npm or yarn / pnpm

### Installation

```bash
npm install
```

### Development

Start the local development server:

```bash
npm run dev
```

### Production Build

Build the project for production:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```
